# Request Code Access

AsymPT's full training pipeline, model source code, and pre-trained weights are kept private to support ongoing research.

## What you'll get

- Full model source (`models/` directory)
- Training pipeline (`train.py`, `configs/`)
- Evaluation and inference scripts
- Dataset loading utilities for Synapse
- Pre-trained checkpoint (if available)

## How to request

Send an email to **satgunsodhi@gmail.com** with:

1. Your name and affiliation
2. Brief description of your research / intended use
3. Subject line: `[AsymPT] Code Access Request`

All legitimate research requests will be responded to within 48 hours.
